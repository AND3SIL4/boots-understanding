# ACC-XXX — Nombre del acceso

Qué acceso es y para qué se necesita. **Nunca escribir credenciales,
contraseñas, tokens ni rutas a secretos en esta nota** — solo describir
qué se requiere y dónde está custodiado.

- **Tipo:** usuario de servicio / usuario nominal / API key / certificado
- **Sistema:** [[Sistema - nombre-sistema]]
- **Permisos requeridos:** perfil, rol o transacción mínima necesaria
- **Dónde se custodia:** bóveda del orquestador, gestor de secretos, etc.
- **Caducidad / rotación:** si el documento lo especifica
